# Norwegian Naming Patterns for AI/SaaS Products

## Personal Name Pattern ("Hei + [name]")

The most successful Norwegian AI receptionist brands use a personal name that sounds like someone you'd greet on the phone:

- **heiemma.no** — "Hei Emma" (competitor)
- **heikari.no** — "Hei Kari" (competitor)

This pattern works because it feels like a real person, not a service.

### Pitfall: Unintentional word combinations
Norwegian compound names can spell unintended words. "Hei" + "Lise" = "Heilise" which partially spells "heil" (Nazi greeting). Always check the visual拼写 of the combined name for unintended reads.

### Pitfall: Competitor proximity
If a competitor uses "heikari", names like "heimari" feel derivative and cause confusion. Choose a distinct prefix or drop the "hei" pattern entirely.

## Concept-Based Patterns

When "Hei + [name]" is saturated or problematic, try these Norwegian compound patterns:

### "Svar" (answer) compounds
- **svaria** — "svar" + "-ia" suffix (elegant, name-like)
- **evigsvar** — "evig" (eternal) + "svar" (answer)
- **fastsvar** — "fast" (fixed/quick) + "svar"
- **alltidsvaret** — "alltid" (always) + "svaret" (the answer)
- **autosvaret** — "auto" + "svaret" (the automatic answer)
- **dittsvar** — "ditt" (your) + "svar"

### "Trygg" (safe/trusted) compounds
- **tryggsofie** — "trygg" + personal name

### "Alltid" (always) compounds
- **alltidsofie** — "alltid" + personal name

### Abstract name-like (no literal meaning)
- **svaria** — sounds like a name, has "svar" embedded
- **kresto**, **vorso** — Klarna-style, no meaning but catchy

## Naming Decision Framework

1. **Start with personal names** (hei+[name]) — most approachable
2. **If competitor proximity is an issue**, switch to concept compounds (svar+, trygg+, alltid+)
3. **If compound feels generic**, try abstract name-like words (svaria, kresto)
4. **Always check**: unintended word combinations, competitor proximity, pronunciation on the phone
